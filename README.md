# Sabuk Teluk Cirebon - Restorasi Mangrove Pantura

Sistem showcase dan landing page ilmiah untuk inisiatif konservasi ekologi mangrove pesisir utara Jawa Barat (Stasiun Kasugengan Lor, Teluk Cirebon).

## Tech Stack
- **Framework:** Vite + React 18 (TypeScript)
- **Styling:** Tailwind CSS + Custom CSS Variables (:root)
- **3D Graphics:** Three.js (Procedural Bathymetry, Wireframe DEM, Low-power WebGL)
- **Motion:** GSAP 3.12 + `@gsap/react` + `ScrollTrigger`
- **Typography:** Instrument Serif + Geist + Geist Mono
- **Design Standard:** Swiss Cartographic Grid & Anti-Slop (miqdadbadjuber/anti-slop)

## Getting Started

```bash
# Install dependencies
bun install

# Start local development server
bun run dev

# Build for production
bun run build

# Preview production build
bun run preview
```

## Features
- **Floating Island Navigation:** Glassmorphic pill navigation with micro-interactions.
- **Double-Bezel Hardware Frame:** Outer shell & inner core containing real-time 3D bathymetric seabed simulation.
- **Interactive 3D WebGL:** Procedural substrate slope, wave breathing, and Rhizophora prop root structures with pointer parallax and automatic viewport observer.
- **Asymmetrical 12-Column Bento Grid:** High-density quantitative metrics (34.8 Ha bio-barrier, 14,200 propagules, 18 community groups).
- **Interactive Monitoring Ledger:** Filterable station matrix across 4 observation points in Cirebon Bay.
